# MaVoid Portfolio

A bilingual (English / Arabic) project portfolio for MaVoid — filter by category, open project detail, and reach out on WhatsApp.

For MaVoid and client stakeholders who want a living showcase of shipped work, not a static PDF deck.

## What you can do

- Browse projects in a grid and filter by category
- Open a project modal for more detail (deep-linkable via `?project=`)
- Switch language between English and Arabic
- Message MaVoid from the WhatsApp button
- Manage projects and custom categories from a simple `/admin` view (Firebase-backed)

## Try it

Clone the repo, install deps (`npm install`), and run `npm run dev`. No public production URL is listed on the repo yet.

## How it works

Vite + React front end with Firestore for projects and categories, plus an admin route for content updates. Setup notes belong in `docs/` if you add them later.
